Станки на стойке Heidenhain TNC умеют измерять деталь прямо в процессе обработки — без переустановки, без ручного промера штангелем. Но чтобы эта возможность работала правильно, нужно понимать, какой цикл за что отвечает и как передать результат дальше в программу.

В этой статье разберём полную структуру циклов щупа для TNC 640 и iTNC 530: группы 400–499, логику Q-параметров, типичные сценарии применения и ключевые ограничения.

---

## Как устроена система циклов щупа в TNC


Циклы щупа используют Q-параметры с номерами 400 и выше в качестве параметров передачи данных.
 Это принципиально важно: результат каждого измерения — угол перекоса, координата центра, диаметр отверстия — попадает в конкретный Q-параметр, который можно сразу использовать в управляющей программе для коррекции обработки.

Все циклы щупа в TNC делятся на несколько функциональных групп. Каждая группа решает свою задачу и имеет собственный диапазон номеров.

| Группа | Диапазон номеров | Назначение |
|---|---|---|
| Компенсация перекоса | 400–405 | Измерение угла разворота заготовки |
| Привязка нуля детали | 408–419 | Установка рабочего нуля по элементам детали |
| Измерение элементов | 420–431 | Контроль размеров, координат, плоскостей |
| Специальные функции | 440–441 | Компенсация смещения оси, быстрое зондирование |
| Кинематика | 450–451 | Измерение и сохранение кинематики станка |
| Измерение инструмента | 480–487 | Автоматическая привязка и контроль инструмента |

> **Ключевое правило:** 
при выполнении циклов щупа 400–499 все активные трансформации координат должны быть отключены.
 Перед вызовом цикла сбросьте Cycle 7 (DATUM SHIFT), Cycle 10 (ROTATION) и TRANS-команды.

---

## Группа 400–405: компенсация перекоса заготовки

Это первое, что выполняется в большинстве измерительных программ. Заготовка никогда не устанавливается в тиски идеально — всегда есть угловое отклонение. Циклы этой группы его измеряют и вносят в базовый поворот (Basic Rotation).


Доступны следующие варианты:
- **Цикл 400 (BASIC ROTATION)** — измерение перекоса по двум точкам на поверхности;
- **Цикл 401 (BASIC ROTATION from two holes)** — базовый поворот через центры двух отверстий;
- **Цикл 402 (BASIC ROTATION over two studs)** — базовый поворот через центры двух бобышек;
- **Цикл 403** — компенсация перекоса через поворотную ось;
- **Цикл 404 (SET BASIC ROTATION)** — ручная установка базового поворота;
- **Цикл 405** — компенсация перекоса поворотом оси C.


**Цикл 401 в деталях**


Цикл 401 измеряет центры двух отверстий. Затем TNC вычисляет угол между осью отсчёта в рабочей плоскости и линией, соединяющей центры отверстий. С помощью функции базового поворота TNC компенсирует вычисленное значение.
Перед определением цикла необходимо запрограммировать вызов инструмента (TOOL CALL) для задания оси щупа.
TNC сохраняет базовый поворот в энергонезависимой памяти — он остаётся активным для всех последующих запусков программ.

## Группа 408–419: привязка нуля детали

После компенсации перекоса нужно выставить рабочий ноль. Эта группа циклов зондирует геометрические элементы детали и автоматически записывает результат в таблицу предустановок (Preset Table) или таблицу нулей.


Доступны следующие циклы:
- **Цикл 410 (DATUM FROM INSIDE OF RECTANGLE)** — ноль из внутренней прямоугольной формы (карман);
- **Цикл 411 (DATUM FROM OUTSIDE OF RECTANGLE)** — ноль снаружи прямоугольного выступа;
- **Цикл 412 (DATUM FROM INSIDE OF CIRCLE)** — ноль по внутреннему диаметру отверстия.
Также доступны циклы 408 и 409 (SLOT CENTER REFERENCE POINT) — привязка нуля по центру паза.


**Запись результата в таблицу предустановок**


Параметры с определёнными функциями, используемые в нескольких циклах, всегда имеют одни и те же номера Q-параметров
 — это упрощает написание универсальных макросов. Например, Q305 традиционно задаёт номер строки в таблице предустановок, куда будет записан результат. Если задать Q305 = 0, ноль устанавливается немедленно в активную систему координат без записи в таблицу.

> **Важно:** записывайте результат в таблицу предустановок (Q305 > 0), а не только в текущий ноль. Это позволяет воспроизвести привязку после аварийного останова или смены программы без повторного зондирования.

---

## Группа 420–431: измерение элементов детали

Это основная группа для контроля размеров непосредственно на станке (on-machine measurement). Результаты попадают в Q-параметры и могут использоваться для автокоррекции инструмента.


В группу входят:
- **Цикл 427 (MEASURE COORDINATE)** — измерение координаты точки по любой оси;
- **Цикл 426 (MEASURE RIDGE WIDTH)** — измерение ширины выступа;
- **Цикл 430 (MEAS. BOLT HOLE CIRC)** — измерение диаметра и углового положения отверстий на окружности;
- **Цикл 431 (MEASURE PLANE)** — измерение плоскости по трём точкам.


**Пример: Цикл 427 для контроля глубины кармана**

```
CYCL DEF 427 MEASURE COORDINATE
Q263=+50    ; 1-я точка по 1-й оси
Q264=+30    ; 1-я точка по 2-й оси
Q261=-5     ; Высота измерения
Q320=+2     ; Зазор безопасности
Q272=3      ; Ось измерения (Z)
Q267=+1     ; Направление движения
Q260=+50    ; Высота безопасности
Q281=1      ; Измерение с протоколом
CYCL CALL
```

Результат записывается в Q160. Далее можно сравнить Q160 с номинальным значением и через IF/GOTO выйти в аварийный останов или скорректировать коррекцию инструмента.


Пример из документации Heidenhain: измерение прямоугольного выступа с записью результатов в протокол и последующая переработка по результатам измерения.

## Группа 440–441: специальные функции


Цикл 440 (MEASURE AXIS SHIFT) — измерение смещения оси щупа. Цикл 441 (FAST PROBING) — быстрое зондирование, позволяет задать повышенную скорость предпозиционирования для сокращения времени измерения.


Цикл 441 особенно полезен в серийном производстве, где время цикла критично: щуп выходит в точку на ускоренном ходу, а зондирование происходит уже на рабочей подаче, заданной в параметрах щупа.

---

## Группа 450–451: измерение кинематики


Цикл 450 (SAVE KINEMATICS) — сохранение текущей кинематики станка. Цикл 451 (MEASURE KINEMATICS) — автоматическое измерение и компенсация погрешностей кинематики с помощью калибровочной сферы.


Эти циклы относятся к опции KinematicsOpt и требуют отдельной лицензии у производителя станка. Они позволяют компенсировать термодрейф поворотных осей и восстанавливать кинематику после ТО без ручной выверки.

---

## Измерение инструмента: циклы 480–487

Для автоматической привязки и контроля инструмента TNC использует отдельную группу циклов, работающих со стационарным датчиком TT (Tool Touch Probe) или лазерной системой.

| Цикл | Назначение |
|---|---|
| 480 | Калибровка датчика инструмента |
| 481 | Измерение длины инструмента |
| 482 | Измерение радиуса инструмента |
| 483 | Полное измерение (длина + радиус) |
| 484 | Контроль поломки — без обновления коррекции |
| 487 | Измерение инструмента лазерной системой |

> **Ключевое правило:** цикл 484 используется только для контроля целостности инструмента — он не обновляет коррекцию в таблице, а лишь сигнализирует о поломке. Для полной привязки используйте цикл 483.

## Важные технические ограничения


При выполнении циклов 444 и 14xx не должны быть активны следующие трансформации: Cycle 8 (MIRRORING), Cycle 11 (SCALING FACTOR), Cycle 26 (AXIS-SPECIFIC SCALING) и TRANS MIRROR.


Несоблюдение этого требования приводит к неправильным результатам измерения или столкновению щупа с деталью — без какого-либо предупреждения на экране.

Также необходимо учитывать:
- Параметр **MP6130** задаёт максимальный путь движения до точки зондирования. Если щуп не касается поверхности на этом расстоянии — ошибка.
- Параметр **MP6140** — зазор безопасности до точки зондирования при предпозиционировании.
- Параметр **MP6170** — количество повторных измерений для усреднения результата.

## Быстрая памятка: как работать с циклами измерения Heidenhain

1. **Сбросьте трансформации** → перед вызовом любого цикла группы 400–499 отключите DATUM SHIFT, ROTATION, MIRRORING
2. **Скомпенсируйте перекос** → циклы 400–405 первыми, до привязки нуля
3. **Установите ноль** → циклы 410–419, результат — в таблицу предустановок (Q305 > 0)
4. **Измерьте элемент** → циклы 420–431, результат — в Q-параметр для дальнейшего использования
5. **Проверьте инструмент** → цикл 483 для полной привязки, цикл 484 для контроля поломки
6. **Запишите протокол** → Q281 = 1 формирует файл измерения на TNC
