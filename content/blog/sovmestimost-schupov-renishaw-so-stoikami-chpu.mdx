Купить правильный щуп Renishaw — это половина задачи. Вторая половина — подключить его к стойке ЧПУ так, чтобы он заработал: передавал сигнал, запускал циклы измерения и корректировал смещения автоматически.

Эта статья — справочник по совместимости. Разбираем три самые распространённые стойки на российских предприятиях: Fanuc, Siemens 840D и Heidenhain TNC/iTNC.

---

## Как щуп «разговаривает» со стойкой

Прежде всего — схема взаимодействия. Щуп не просто касается детали и «говорит» стойке остановиться. Система работает сложнее:

1. Шпиндель подводит щуп к поверхности детали на заданной скорости измерения
2. Щуп касается поверхности → срабатывает контакт → датчик отправляет сигнал пропуска (skip signal)
3. Стойка ЧПУ получает сигнал и фиксирует текущие координаты всех осей в момент срабатывания
4. Макрос или цикл обрабатывает эти координаты: вычисляет смещение заготовки, длину инструмента, отклонение от номинала
5. Стойка автоматически вносит поправки в систему координат (G54–G59) или в таблицу инструментов

**Вывод:** щупу нужен не просто физический сигнал «сработало», но и программная оболочка — макросы или встроенные циклы — которая умеет с этим сигналом работать.

## Fanuc: серии 0i, 16i/18i/21i, 30i/31i/32i

Fanuc — самая распространённая стойка в мире и в России. Рениshaw поддерживает её в полном объёме.

### Интерфейс подключения

| Тип датчика | Интерфейс | Примечание |
|---|---|---|
| TS27R (проводной, инструмент) | HSI или прямой вход пропуска | Подключается через клеммную колодку стойки |
| OMP40-2 / OMP60 (ИК, заготовка) | Приёмник OMI-2T → стойка | Приёмник подаёт сигнал на вход «skip» |
| RMP60 QE (радио, заготовка) | Приёмник RMI-Q → стойка | Аналогично OMI-2T |

### Программная оболочка

На Fanuc циклы измерения реализуются через **макросы пользователя** (Custom Macro B). Renishaw поставляет готовые макросы серии **Inspection Plus (OMC)**:

- Макросы устанавливаются в память стойки (PMC или CNC Memory)
- Вызываются стандартными G-кодами: `G65 P9810` (защищённое перемещение), `G65 P9811` (одиночное касание), `G65 P9812` (центрирование кармана) и т.д.
- Поддерживают автоматическую запись в регистры смещений G54–G59 и в таблицу инструментов

**Серии Fanuc и совместимость:**

| Серия Fanuc | Поддержка макросов Renishaw | Примечание |
|---|---|---|
| 0i-MD / 0i-MF | Полная | Наиболее распространена на новых станках |
| 16i / 18i / 21i | Полная | Классика, огромный парк |
| 30i / 31i / 32i | Полная | Высокоскоростные станки |
| 0-MC / 0-MD (старые) | Ограниченная | Может потребоваться адаптация макросов |
| Series 15 | Не поддерживается стандартными макросами | Нужна отдельная разработка |

> **Важный момент:** Fanuc требует активации опции Custom Macro B (Option G). Если она не активирована в вашей стойке — макросы не запустятся. Уточните у производителя станка или проверьте через `MDI → Параметры → Опции`.

### Пример вызова цикла на Fanuc

```gcode
; Включение щупа
M19          ; Ориентация шпинделя (если требуется)
M51          ; Включение щупа (M-код зависит от конфигурации)

; Измерение поверхности в направлении -Z
G65 P9811 X0. Y0. Z-50. D50. F300.
; X, Y — позиция подхода; Z — глубина касания; D — номинал; F — скорость

; Результат записывается в #149 (смещение по Z)
; Автоматическая запись в G54
G65 P9813 D1.   ; Обновить G54 с учётом измеренного смещения
```

## Siemens Sinumerik 840D / 828D

Синемерик — вторая по распространённости стойка на российских ОЦ, особенно на станках немецкого и чешского производства.

### Интерфейс подключения

Схема подключения аналогична Fanuc: приёмник (OMI-2T или RMI-Q) подаёт сигнал на вход **быстрого останова** стойки — в Siemens это вход **BERO** или **digital input** в NCU.

На Siemens 840D важно правильно настроить **машинный параметр MD 11450** (реакция на сигнал пропуска). Неправильная настройка — частая причина, почему щуп срабатывает, а стойка «не видит» касания.

### Программная оболочка

Siemens 840D sl поддерживает два варианта работы со щупами Renishaw:

**Вариант 1: Renishaw Inspection Plus для Siemens**
Аналог макросов для Fanuc, адаптированный под язык Siemens (ISO или ShopMill). Циклы вызываются через подпрограммы:
- `CYCLE977` — одиночное касание
- `CYCLE978` — измерение поверхности
- `CYCLE979` — центрирование

**Вариант 2: Встроенные циклы Siemens (Measuring Cycles)**
Начиная с Sinumerik 840D sl версии SW 4.4+, в стойку встроены циклы измерения (опция «Measuring Cycles»). Они работают со стандартным входом пропуска без дополнительных макросов Renishaw.

| Стойка | Рекомендуемый вариант |
|---|---|
| 840D sl, SW 4.4+ | Встроенные Measuring Cycles или Renishaw Inspection Plus |
| 840D sl, старые версии | Renishaw Inspection Plus |
| 828D | Renishaw Inspection Plus (встроенные циклы ограничены) |
| 802D sl | Ограниченная совместимость, нужна проверка |

> **Примечание:** если на станке установлена оболочка **ShopMill**, циклы измерения можно вызывать прямо из графического интерфейса — без ручного написания G-кода. Это существенно упрощает работу оператора.

### Пример вызова на Siemens 840D (ISO-режим)

```gcode
; Подвод к детали, щуп включён
M_PROBE_ON      ; M-код включения щупа (настраивается в PLC)

; Измерение поверхности
CYCLE977(1, 1, 0, 0, -50, 50, 3, 0.1, 1, 54, 0, 0, 0, 0, 0, 0)
; Параметры: направление, ось, координаты, номинал, допуск, G-регистр

M_PROBE_OFF     ; Выключение щупа
```

## Heidenhain iTNC 530 / TNC 620 / TNC 640

Heidenhain — стойка, которую ставят на прецизионные европейские станки: Hermle, DMG Mori (некоторые серии), Chiron, Röders. Отличается от Fanuc и Siemens нестандартным языком программирования (диалект HEIDENHAIN).

### Интерфейс подключения

Heidenhain имеет **нативный вход для щупа** (Probing Input, разъём X32 или X34 на блоке ввода/вывода). Это упрощает подключение: приёмник OMI-2T или RMI-Q подключается напрямую, без сложной настройки параметров.

Важно: Heidenhain различает два типа входов:
- **Быстрый вход пропуска (Fast Probe Input)** — реакция менее 1 мс, используется для измерения
- **Обычный цифровой вход** — реакция 5–10 мс, для этого не подходит

Убедитесь, что приёмник подключён именно к быстрому входу — иначе точность измерения резко падает.

### Программная оболочка

Heidenhain имеет **встроенные циклы щупа** (Touch Probe Cycles), которые включены в базовую поставку стойки. Это одно из главных удобств iTNC/TNC:

| Цикл | Назначение |
|---|---|
| Cycle 0 | Ручное измерение (справочное) |
| Cycle 3 | Измерение в направлении оси |
| Cycle 408–416 | Центрирование карманов, бобышек, угол разворота |
| Cycle 420–431 | Контроль детали в автоматическом цикле |
| Cycle 480–483 | Калибровка щупа |
| Cycle 33 | Контроль инструмента (с TS27R) |

Дополнительные макросы Renishaw для Heidenhain, как правило, не нужны — встроенные циклы покрывают все типовые задачи.

### Пример цикла на TNC 640

```
; Вызов Cycle 408 — центрирование круглого кармана
CYCL DEF 408 CENTERING IN POCKET ~
  Q321=+50      ; Центр X
  Q322=+30      ; Центр Y
  Q323=80       ; Диаметр кармана (номинал)
  Q261=-5       ; Глубина измерения
  Q305=0        ; Номер в таблице смещений (0 = активная)
  Q381=1        ; Обнулить ось C: да

CYCL CALL
```

### Версии TNC и поддержка

| Стойка | Встроенные циклы щупа | Примечание |
|---|---|---|
| iTNC 530 | Полная, циклы 0–431 | Устаревшая, но на большом парке |
| TNC 620 | Полная | Средний класс |
| TNC 640 | Полная, расширенные циклы | Текущее поколение |
| TNC 7 | Полная + новые циклы | Новейшая, станки с 2021+ |
