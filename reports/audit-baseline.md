# Базовый SEO-аудит

**Сформирован:** 2026-09-10T06:59:09.970Z

## Инвентаризация

- Framework: Next.js 16, App Router, React 19, TypeScript; страницы серверные и статически генерируемые.
- Роутинг: `src/app`; товары — JSON в `content/products`, статьи — MDX в `content/blog`, категории и информационные тексты — JSON в `content`.
- Обнаружено: **578 товаров**, **125 статей**, **5 категорий**, **12 статических URL**. В ТЗ заявлено 140 статей, но в репозитории фактически 125; отсутствующие 15 нельзя включить без исходного контента.
- Metadata формируется в page-модулях через Metadata API; canonical добавлен ключевым шаблонам. Open Graph есть глобально и на товарах/статьях.
- JSON-LD: Organization глобально, Product и BreadcrumbList в карточке, Article и BreadcrumbList в статье.
- Meta robots: глобально не ограничивает индексацию; robots.ts разрешает обход.

## Аналитика и цели

- Яндекс.Метрика 109048844 подключена с webvisor, clickmap и trackLinks.
- Google Analytics подключается только при наличии `NEXT_PUBLIC_GA_ID`; ID в репозитории отсутствует.
- Специализированные события успешных отправок форм ещё требуют проверки в реальных кабинетах аналитики. Подтверждение Webmaster/Search Console невозможно выполнить из репозитория без доступа владельца.

## Открытые ограничения

- Юридические реквизиты и фотографии отсутствовали в исходных данных и явно обозначены TODO.
- Реальную доставку SMTP нельзя подтвердить без production credentials; API возвращает диагностируемые статусы и не раскрывает внутреннюю ошибку.
- Политика и согласие являются шаблонами и требуют согласования с юристом.
