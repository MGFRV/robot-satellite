# Сравнение с https://renishaw-rus.com/#orders (04.05.2026)

Краткий список улучшений для внедрения:

1. Добавить «Заказы» как отдельный якорный раздел на главной с пошаговым процессом закупки (бриф → КП → оплата/доставка).
2. Вынести быстрые каналы связи в шапку: телефон, WhatsApp, Telegram, email.
3. Добавить блок «В наличии и под заказ» с SLA (например, ответ за 10 минут) и CTA.
4. Добавить карточки преимуществ с конкретными цифрами (срок поставки, число SKU, охват регионов).
5. Усилить карточки товара: больше технических параметров и кейсы применения.
6. Добавить «Соцдоказательства»: логотипы клиентов, отзывы, кейсы внедрения.
7. Добавить явный FAQ по заказу, совместимости, доставке, документам.
8. Добавить микроконверсии: кнопки «Отправить запрос» после каждого товарного блока/категории.
9. Добавить структурированные SEO-блоки под коммерческие запросы (дилер, поставка, сроки, регионы).
10. Добавить аналитику событий и воронку (клики по CTA, отправка форм, добавление в список запроса).

Примечание: в текущем проекте уже есть сильные функции каталога, поиска, формы RFQ и корзины-запроса — их стоит сохранить как дифференциатор.
